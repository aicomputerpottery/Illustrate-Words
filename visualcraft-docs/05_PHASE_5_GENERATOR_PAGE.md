# Phase 5 — Generator Page (The Wizard — Main Product)

## Goal
Build the interactive four-step wizard that generates polished prompt text.

## Deliverables
- Step-by-step wizard UI
- Visualization type selection
- Color palette selection
- Style options
- Prompt generation and copy actions
- Local persistence and URL state

## Implementation Notes
- Use vanilla JavaScript for the state machine.
- Keep the experience fast and offline-first.
- Make the generated prompt easy to copy and reuse.

## Verification
- Test the full flow from start to finish.
- Confirm the generated prompt updates correctly as options change.
