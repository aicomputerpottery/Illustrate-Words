# Phase 4 — Home Page (Landing)

## Goal
Create a polished marketing landing page that sells the product and explains the experience.

## Deliverables
- Hero section
- How it works section
- Categories preview grid
- Comparison section
- Testimonials or use cases
- Final call-to-action

## Implementation Notes
- Keep the page visually strong and conversion-focused.
- Add subtle motion with CSS or lightweight JS.
- Make mobile-first responsiveness a priority.

## Verification
- Confirm the page looks good at desktop and mobile widths.
- Ensure all CTAs navigate to the generator page.
